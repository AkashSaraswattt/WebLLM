# 🧠 WebLLM - AI Agent in Your Browser

> Run powerful language models directly in your browser using WebLLM — no server, no API key, just pure local LLM magic.

![WebLLM Screenshot](./public/vite.svg)

## 🚀 Features

- 🧠 Run Large Language Models locally in-browser (GGML, WebGPU-based)
- ⚡ Instant inference, no API calls
- 🌐 Built with Vite + React for blazing fast dev experience
- 🛡️ Fully private — no data leaves your browser

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Model Engine:** WebLLM (via WebGPU)
- **Styling:** CSS (custom or Tailwind-ready)
- **Bundler:** Vite
- **Tooling:** ESLint, Prettier
